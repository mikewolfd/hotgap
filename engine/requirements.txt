# The model, pinned: these three decide every number the service returns.
#
# `policyengine-us`'s own metadata (2.4.2 through 2.5.0) asks for
# `spm-calculator>=1.0.0,<=1.0.0.post1` while its README prose says the
# release "pins spm-calculator==0.3.1 to preserve its SPM threshold API". The
# metadata is the machine-readable truth and the resolver picks 1.0.0.post1;
# SPM thresholds were checked under it (a CA family of two, 2026: $37,779)
# and are sane, so the metadata's range is what is pinned here. Revisit if
# upstream corrects the prose in a later release.
#
# 2.5.0 (2026-09-16) carries 2.4.4's fix for the Massachusetts TAFDC double
# count (policyengine-us #9478) and 2.4.3's Massachusetts CCFA rework; the
# client detects the first by probing. 2.5.2 carries the corrected parent
# Medicaid limits (#9475, #9499), which the client's version check retires
# its own override on. 2.5.3 counts state SSI supplements as SNAP unearned
# income; 2.6.x is state tax and reform aggregates. The federal CCDF chain
# 2.5.0 removed was never requested.
policyengine-us==2.6.7
policyengine-core==3.32.6
spm-calculator==1.0.0.post1

# The HTTP layer. Flask because the public API is a Flask app, and gunicorn
# because a simulation is not safe to interleave with another in the same
# process (engine/calculate.py), so parallelism has to come from processes.
flask==3.1.3
gunicorn==26.2.0
